# Domain Docs

## Before exploring

Read:

- Root `CONTEXT.md`
- Relevant ADRs under `docs/adr/`

Missing files do not block work.

## Layout

This is a single-context repository:

- `CONTEXT.md` defines the shared vocabulary.
- `docs/adr/` records architectural decisions.

## Vocabulary

Use terms exactly as defined in `CONTEXT.md`. Avoid introducing synonyms for existing domain concepts.

## ADR conflicts

If proposed work contradicts an ADR, report the conflict explicitly instead of silently overriding it.
